# Learning-link-label

Playground to test combinations of text, aria-label, title, icons in links and what is conveyed to users in screen readers (Voice Over).

Prompted by a conversation with [frkfrontend](https://bsky.app/profile/frkfrontend.no), hence the links to her site.

## Setup

Bootstrapped using `npm create vite@latest` to have a dev server and bundler available just in case.

To run on your computer:

```sh
npm install
npm run dev
```
